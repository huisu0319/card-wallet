# CARD WALLET — 명함 지갑 (모바일 앱)

받은 명함을 기록해 모아두는 개인용 앱. 이름·회사·연락처를 적으면 **명함 한 장당 컬러 하나**의
랜덤 디자인이 생성되고, 지갑 안에 겹쳐 꽂힙니다. 명함을 탭하면 **지갑에서 뽑히듯** 튀어나옵니다.

## 실행
- **PC**: `index.html`을 브라우저에서 열면 화면 가운데에 앱 화면으로 뜹니다.
- **폰**: 같은 와이파이에서 아래 명령으로 서버를 켜고 `http://<맥의 IP>:4399` 접속.

```bash
cd card-wallet && python3 -m http.server 4399
```

- **홈 화면에 앱으로 추가**: 사파리/크롬에서 접속 → 공유 → "홈 화면에 추가".
  `manifest.json` + `sw.js`가 있어 주소창 없는 전체 화면으로 실행되고, 오프라인에서도 열립니다.

## 화면
- 하단 탭바: **지갑** · **＋(추가)** · **전체**
- 상단: 검색(돋보기), 백업 메뉴(···)

## 사진으로 추가 (자동 인식)
＋ 를 누르면 세 가지 중에 고릅니다.

- **카메라로 찍기** — 앱 안에서 카메라가 켜집니다. 명함을 가이드 사각형에 꽉 채우고 셔터를 누르면
  그 사각형 영역만 잘라서 읽습니다. (카메라가 둘 이상이면 전환 버튼이 나타납니다)
- **사진 고르기** — 이미 찍어 둔 명함 사진을 앨범·파일에서 고릅니다.
- **직접 입력** — 손으로 적습니다.

앞의 두 가지는 폰·PC 안에서 글자를 읽어 이름·회사·직함·연락처·메일·주소를 자동으로 채운 뒤
확인 화면을 띄웁니다. 고칠 곳만 손보고 저장하면 랜덤 디자인이 배정되어 지갑에 들어갑니다.

> 카메라는 `https` 또는 `localhost`에서만 열립니다. `index.html`을 파일로 직접 열면
> **카메라로 찍기** 항목이 자동으로 숨겨지니, 카메라를 쓰려면 아래 서버 명령으로 실행하세요.

- **온디바이스 OCR**: Tesseract.js(kor+eng). API 키·서버·비용이 없고 사진이 밖으로 나가지 않습니다.
  처음 한 번만 한글 인식 데이터(약 15MB)를 내려받고, 이후로는 캐시를 씁니다.
- **큰 글씨 재시도**: 명함의 큰 이름 글자는 자동 레이아웃 분석이 통째로 놓치기도 해서,
  이름을 못 찾으면 위쪽만 잘라 한 덩어리 모드(PSM 6)로 다시 읽습니다.
- **어두운 명함**: 배경이 어두우면 흑백 반전 후 인식합니다.
- **원본 사진 보관**: 찍은 사진은 IndexedDB에 JPEG로 저장되고, 상세 화면의 **원본** 버튼으로 볼 수 있습니다.
  사진이 있는 명함에는 앞면에 작은 카메라 표시가 붙습니다.

인식은 완벽하지 않습니다. 특히 **한글 이름**은 틀릴 때가 있으니 확인 화면에서 꼭 살펴 주세요.
(반듯하게, 명함이 화면을 꽉 채우게, 밝은 곳에서 찍을수록 잘 읽습니다.)

## 인터랙션
- **뽑기**: 지갑 속 명함을 탭하면 위로 뽑혀 나온 뒤 화면 가운데로 날아옵니다. (720ms, 구간별 이징)
- **뒤집기**: 큰 카드를 탭하면 앞/뒷면이 3D로 회전합니다.
- **다시 넣기**: 카드를 아래로 밀거나(스와이프) 왼쪽 위 ∨ 버튼을 누르면 원래 자리로 되돌아갑니다.
- 진동 피드백(지원 기기), 토스트 알림, `Esc` 닫기.

## 명함 디자인
- 15종 팔레트 × 앞면 레이아웃 4종 × 시드 기반 기하학 마크 → 저장 시 자동 배정
- 앞면: 컬러 배경 + 초헤비 타이포 + 마침표. 이름 길이에 따라 글자 크기 자동 조절
- 뒷면: `RECEIVED 날짜` · 회사명 · 직함/태그 · 좌하단 마크 · 하단 연락처
- 마음에 안 들면 상세에서 **디자인** 버튼으로 재추첨

## 저장 방식
브라우저 `localStorage`(키: `card-wallet:v1`). 로그인·서버 없음, 데이터는 그 브라우저 안에만 있습니다.
사진은 `IndexedDB`에 따로 담깁니다. `···` 메뉴의 JSON 백업에는 **사진까지 함께 담기니**
가끔 내보내 두세요. (PC ↔ 폰 이동도 이 파일로)

## 파일
- `index.html` — 앱 셸(앱바 · 지갑 · 탭바 · 상세 · 입력 시트 · 인식 화면)
- `css/style.css` — 앱 UI와 명함 디자인
- `js/app.js` — 저장, 랜덤 디자인 생성, 뽑기 애니메이션, 카메라·사진 추가 흐름
- `js/photo.js` — 사진 보관(IndexedDB), OCR 전처리·인식, 명함 항목 추출
- `manifest.json` · `icon.svg` · `sw.js` — 홈 화면 앱 설치용
