# CARD WALLET — 명함 지갑 (모바일 앱)

받은 명함을 기록해 모아두는 개인용 앱. 이름·회사·연락처를 적으면 **명함 한 장당 컬러 하나**의
랜덤 디자인이 생성되고, 지갑 안에 겹쳐 꽂힙니다. 명함을 탭하면 **지갑에서 뽑히듯** 튀어나옵니다.

## 실행
- **PC**: `index.html`을 브라우저에서 열면 화면 가운데에 앱 화면으로 뜹니다.
- **폰**: 같은 와이파이에서 아래 명령으로 서버를 켜고 `http://<맥의 IP>:4399` 접속.

```bash
cd card-wallet && python3 -m http.server 4399
```

- **홈 화면에 앱으로 추가**: 사파리/크롬에서 접속 → 공유 → "홈 화면에 추가".
  `manifest.json` + `sw.js`가 있어 주소창 없는 전체 화면으로 실행되고, 오프라인에서도 열립니다.

## 화면
- 하단 탭바: **지갑** · **＋(추가)** · **전체**
- 상단: 검색(돋보기), 백업 메뉴(···)

## 인터랙션
- **뽑기**: 지갑 속 명함을 탭하면 위로 뽑혀 나온 뒤 화면 가운데로 날아옵니다. (720ms, 구간별 이징)
- **뒤집기**: 큰 카드를 탭하면 앞/뒷면이 3D로 회전합니다.
- **다시 넣기**: 카드를 아래로 밀거나(스와이프) 왼쪽 위 ∨ 버튼을 누르면 원래 자리로 되돌아갑니다.
- 진동 피드백(지원 기기), 토스트 알림, `Esc` 닫기.

## 명함 디자인
- 15종 팔레트 × 앞면 레이아웃 4종 × 시드 기반 기하학 마크 → 저장 시 자동 배정
- 앞면: 컬러 배경 + 초헤비 타이포 + 마침표. 이름 길이에 따라 글자 크기 자동 조절
- 뒷면: `RECEIVED 날짜` · 회사명 · 직함/태그 · 좌하단 마크 · 하단 연락처
- 마음에 안 들면 상세에서 **디자인** 버튼으로 재추첨

## 저장 방식
브라우저 `localStorage`(키: `card-wallet:v1`). 로그인·서버 없음, 데이터는 그 브라우저 안에만 있습니다.
`···` 메뉴에서 JSON 백업/복원이 가능하니 가끔 내보내 두세요. (PC ↔ 폰 이동도 이 파일로)

## 파일
- `index.html` — 앱 셸(앱바 · 지갑 · 탭바 · 상세 · 입력 시트)
- `css/style.css` — 앱 UI와 명함 디자인
- `js/app.js` — 저장, 랜덤 디자인 생성, 뽑기 애니메이션
- `manifest.json` · `icon.svg` · `sw.js` — 홈 화면 앱 설치용
